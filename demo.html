About the contract

Every adapter — Leptos, React, Svelte, Vue, SolidJS, Preact — speaks the same three things.

• kebab-case HTML attributes in — label, description

• CustomEvents out — click a card to fire card-clicked

• Shared CSS variables — --wc-color-primary, --wc-color-text, --wc-radius, --wc-font
